# AgentSpace v1.0.4

这一版加了个新东西：**数据管理** —— 把本机的智能体、Skills、MCP server、Pi 扩展
导出一个包，换台机器再导回来。

顺带把滚动条收拾了一遍（原来太粗），也修了几个界面上的毛病。

---

## 新增

### 数据管理：导出 / 导入本地配置

「系统设置」里多了一张「数据管理」卡片，两个按钮：**导出数据** / **导入数据**。

**导出**时勾选要带走的东西：

- 智能体（可多选）
- Skills（可多选）
- MCP server（可多选）
- Pi 扩展（可多选）

勾了智能体，它引用的 skill / MCP / 扩展会自动一起带出来（界面上标「随智能体带出」）
—— 智能体本身只存路径引用，不把被引用的东西带上，导过去就是个空壳。
自己手动取消某一项也尊重。

**远程来源的只记下载链接，本地手写的打包原文件**

这是这版的核心取舍：

- **远程的** —— skill 来自某个 git 仓库、扩展是 npm 装的、MCP server 来自官方
  registry：只记下它的地址。塞一份文件副本反而更糟 —— 副本不会跟着上游更新，
  用户下次更新时拿到的还是旧内容。
- **本地的** —— 用户自己写的 skill、自己填的 MCP server、自己写的扩展：
  没有下载链接，不打包就真没了。

导入时按同样的规则反向处理：远程的重新拉（git clone / `npm install` / 查目录），
本地的写回本地目录。

导出来的是一个 zip，里面有 `manifest.json` 清单 + 各条数据的文件。

### 导入时能选要不要覆盖

同名就是冲突。**默认不覆盖**（跳过）—— 导入是增量动作，不该把本机已有的东西
悄悄冲掉。

冲突清单按类型分组（跟导出弹窗一致：智能体 / Skills / MCP server / Pi 扩展），
每条一个「覆盖」勾选框，**默认全不勾**。每组还有个「全选覆盖」
（勾了一部分时是半选状态）—— 一个包几十条冲突时，一条条勾太累。

### 导入是后台跑的

导入可能要拉远程仓库、跑 `npm install` —— 几十秒起步。同步做界面会卡住，
用户以为死了。

所以确认之后不是「等它跑完」，而是「启动它」：进度和结果走事件，
**写到顶栏的通知里**。你可以关掉弹窗去干别的，导入照样跑完，
跑完了铃铛里能看到结果（导入了几项、跳过几项、哪几项失败）。

## 变更

- **滚动条细了**。原来用的是系统默认的滚动条（Windows 上 17px，很粗），
  现在 8px。滚动条出现/消失时内容宽度也不跳了。

- **窗口不再整页滚**。滚动条之前贯穿整个窗口高度 —— 顶栏那一条里也有一条，
  看着像「滑轮顶到了头部」。现在滚动交给内容区，滚动条只在顶栏下面。

- **弹窗右上角不再放关闭按钮**。应用是自绘标题栏（Windows 上没有系统标题栏），
  窗口右上角本来就有 ✕，弹窗再放一个，两个 ✕ 并排，分不清是关弹窗还是关应用。
  关弹窗用底部的「取消」。

---

## 修复

- **侧边栏多出一条横向滑轮**。侧栏改成自己滚之后，`overflow-y: auto` 会把
  `overflow-x: visible` 变成 `auto`（CSS 规范如此），横向一溢出就冒出横滑轮。

- **侧边栏的收起/展开按钮位置不对**。按钮是「骑在侧栏右缝上」的设计，
  侧栏变成滚动容器后 `overflow` 会把骑出去的那半圆裁掉；挪到侧栏外面才解决。

---

## 已知限制

- **便携版（zip 解压即用）不支持应用内更新** —— 它不是安装版，没有可替换的
  安装目录。安装版（`AgentSpace_*_x64-setup.exe`）不受影响。

- 导出的 OAuth 令牌、`tools.json` 缓存、agent 运行历史**不导出** ——
  敏感或没有意义。`${ENV:NAME}` 这类占位原样保留，导入方自己配环境变量。
