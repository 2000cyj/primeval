# AgentSpace v1.0.3

这一版把**更新**整个搬进了应用里。

以前点「更新到 X.Y.Z」，会把浏览器打开，让你自己去 GitHub 找附件、下载 40 多 MB、
自己跑安装程序、装完再自己重开应用 —— 中间哪一步没做对都不清楚。

现在下载、验签、安装、重启**全在应用内完成**，你只需要点那一下。

---

## 新增

### 应用内更新：点一下就完事

用的是 Tauri 官方 updater 插件（跟 cc-switch 同一套）。

- **下载在应用内完成**，不跳浏览器。有进度条，看得见百分比和已下载量（`12.4 / 43.8 MB`）
- **下完自动验签**。minisign 签名校验用内置公钥 —— 公钥编译在应用里，
  用户不需要任何密钥，签名不对的包不会装
- **装完自动重启**。Windows 上安装器以 `/UPDATE` 模式替换掉正在运行的这一份程序，
  装好直接拉起新版
- 全程不用你插手，界面提示「下载完会自动安装并重启」

后端新增 `install_update_and_restart` 命令，下载进度通过 `update-download-progress`
事件推给前端画进度条。

### 发布说明渲染成 Markdown

「检测到新版本」下面那块发布说明，以前是 `<pre>` 包着一坨 Markdown 源码 ——
`**加粗**`、`## 标题`、表格的 `|` 符号全露在外面，像贴了段代码。

现在按 Markdown 渲染：

- 标题、列表、引用、表格、代码块、行内代码、粗体、链接都正常显示
- 渲染结果过一遍 **DOMPurify**，远端 HTML 不会执行
- 展开后的可视高度从 96px 放宽到 220px，能多看几行

### 安装包带签名了

发版流水线现在会用 minisign 给更新包签名，产出 `.sig` 和一份 `updater.json` 清单挂在
release 上。签名私钥只存在 CI 的秘密里，仓库里没有。

---

## 变更

- **发布时间显示成本地时间**。以前直接显示 `2026-11-14T05:50:25Z` 这种 ISO 串，
  现在是 `2026-11-14 13:50:25`（本地时区）

- **「展开全部 / 收起」挪到了提示栏最右边**。以前它挤在「查看发布说明」后面，
  一眼看过去不知道是干什么的；现在靠右对齐，跟左边的版本号、时间戳拉开距离

- **更新失败会说原因**。以前只能打开浏览器，现在下载、验签、安装各环节出错都直接提示

---

## 已知限制

便携版（zip 解压即用）**不支持应用内更新** —— 它不是安装版，没有可替换的安装目录。
安装版（`AgentSpace_*_x64-setup.exe`）不受影响。
