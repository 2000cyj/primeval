# AgentSpace v1.0.1

这一版把「文档」和「更新」两件事补上了。

顶栏多了一个问号，点开是帮助中心 —— 全部命令行操作和各个界面的用法都收在里面，能搜。命令行命令一条一条列，界面按页面讲，说清楚每个按钮点下去会发生什么。

系统设置里「检查最新版本」不再是摆设：它真的去问远端最新版本，比对本地版本，有新版就告诉你，没有就说已是最新。以前那个按钮是留空的，点下去只提示「还没配置检测地址」。

命令行多了 `install` 和 `update`：`agentspace run` 一直是「准备配置 + 拉起 Pi」，现在能把这两件事拆开 —— 只装配置不启动 Pi，或者只更新配置。

另外修掉了 Windows 上点「立即检测」会闪出一堆黑色 CMD 窗口的问题。

---

## 新增

### 帮助中心

顶栏右上角多了一个问号按钮，点开是帮助中心弹窗，分两个页签：

- **命令行**：全部 `agentspace` 命令按分组列出来，每条写明做什么、要注意什么。`run` / `install` / `update` 三个起智能体的命令在最前面，后面是智能体、Skill 仓库、MCP server、Pi 扩展、工具箱、代理六组操作。
- **界面**：按页面讲。Skills、MCP 管理、Pi 扩展、智能体、系统设置，每页写清楚有哪些按钮、点了会发生什么、状态怎么显示。最后有一段通用约定 —— 数据落在哪、绑定怎么存、版本怎么算。

两个页签共用一个搜索框。搜命令名、搜功能名都行，搜到就直接过滤，结果数量显示在搜索框右边。搜不到会明确说「没有匹配的命令」，而不是给一个空列表让人猜。

### 检测最新版本

系统设置里的「检查最新版本」接上真东西了。按钮三个状态：

- 没检查过：**检查最新版本**
- 有新版：**更新到 X.Y.Z**，旁边显示检测到的版本号、发布日期和这一版的发布说明（说明太长可以展开收起）
- 已是最新：**已是最新版本**，按钮禁用

有新版时点「更新到」会直接打开安装包下载；拿不到直链就打开发布页，让人自己挑附件。

检测走四个来源，依次尝试：

1. release 上的 `latest.json` —— CI 每次发版自动生成并挂上去，能拿到附件直链
2. `releases.atom` —— GitHub 的公开订阅源
3. 仓库里的 `latest.json`
4. GitHub API 的 latest release

前面几个不限流，只有最后一个走 API。GitHub 的未认证 API 是 60 次/小时**按 IP 算**的，公司网络里共享出口 IP，这个额度经常被同网段的其他人用光，一用就返回 403。走前几个来源就绕开了这个坑。

### `agentspace install` 与 `agentspace update`

以前只有 `agentspace run` —— 它把绑定的 Skill、指令、MCP 复制到当前目录，然后拉起 Pi。这两件事现在可以拆开：

```bash
agentspace install <智能体名>   # 只落地配置，不启动 Pi
agentspace update <智能体名>     # 覆盖更新已装好的配置
```

- `install` 在空目录里直接装，不多问
- 目录里已经有落地物了，会先问要不要覆盖
- `update` 装的智能体名字对不上，会问是替换成新的还是先装 —— 认错名字就覆盖是很容易后悔的操作
- 装完照样登记 Pi 信任目录，下次启动不弹确认

## 变更

- **不再发布 MSI**。从这一版起只发两种包：`AgentSpace_*_x64-setup.exe`（NSIS 安装包，双击一路下一步）和 `AgentSpace_*_x64_portable.zip`（便携版，解压即用，不写注册表）。MSI 要额外拉一套 wix 工具链，构建慢、失败率高，而且 NSIS 安装包体验一样，收益不大。已经装过 MSI 的不受影响。

---

## 修复

- **Windows 上点「立即检测」会闪出一堆黑色 CMD 窗口**。根因是 Rust 执行绝对路径的 `.cmd` / `.bat` 时，Windows 会自动改走 `cmd.exe /c` 启动，窗口就弹出来了。现在所有外部命令都走统一封装，Windows 下加 `CREATE_NO_WINDOW` 标志，25 处命令启动全部改掉。探测 CLI 版本、装 npm 包、装扩展、启动 sidecar、命令行拉起 Pi 都不再有窗口闪现。
