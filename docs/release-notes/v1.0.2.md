# AgentSpace v1.0.2

这一版是**界面**的一版：换应用图标、把系统标题栏收进应用里、侧边栏能收起、
搜索框不再占地方，另外补齐了文档。

---

## 新增

### 应用内标题栏（Windows）

以前窗口上有**两条** header：上面一条系统标题栏（自带重复的 AgentSpace 图标和标题），
下面一条应用自己的顶栏。两条高度、配色、分隔线各走各的，看着总有一截对不齐。

现在 Windows 上**去掉了系统标题栏**，顶栏自己就是标题栏：

- 顶栏右侧自绘最小化 / 最大化 / 关闭三个按钮（悬停变色，关闭是红的）
- 拖顶栏空白处移动窗口，双击顶栏最大化，拖窗口边缘缩放
- 品牌行（左侧的 logo + AgentSpace）和顶栏**等高、分隔线连成一条**
- macOS / Linux 不受影响，仍用系统标题栏

窗口按钮需要新的权限，已在 `capabilities/default.json` 里补上
（`core:window:allow-minimize / maximize / unmaximize / close / start-dragging / is-maximized`）。

### 侧边栏可以收起了

- 侧边栏右边缝的**中间**有个圆形按钮（`‹` / `›`），一半在侧栏内、一半在主区
- 收起后只剩图标列（56px），logo 居中，**悬停菜单项弹出名字**
- `Ctrl + B` 也能切换
- 收起状态记在 localStorage，下次打开还是上次的样子

### 搜索框：默认只露一个放大镜

Skills、智能体、Pi 扩展三个页面右上角的搜索框，平时只显示一个放大镜图标；
鼠标移上去或点进去才展开成完整输入框（宽度 0.18s 过渡，不跳版）。

### 新应用图标

六边形徽章 + 工具箱，跟「AI 工具箱」这个定位对得上。

- exe 图标、任务栏、Alt-Tab 全部换成新的（`src-tauri/icons/` 整套重生成，
  含 16/24/32/48/64/128/256 多尺寸 ico）
- 侧边栏品牌行和系统设置里的应用图标也换成同一张

## 变更

- **图标不再挤在边缝上**。收起态的收起按钮原来骑在侧栏和主区的交界上，
  白底圆钮压在白色顶栏上像一块白斑；现在改成侧栏右缝**垂直中间**的圆钮，
  位置固定（展开 / 收起都在同一个地方），两种状态都在侧栏内部或只跨一半。

---

## 修复

- **侧栏收起后菜单 Tooltip 盖住标题栏**。之前 Tooltip 默认往上弹，
  收起侧栏时正好弹在左上角，把 logo 和标题栏盖了。改成 `placement="right"`，
  弹在侧栏右侧。

- **收起后点「展开」没反应**。按钮原来是绝对定位跨骑在侧栏边界上，
  主区画在它上面，点击被吃掉。改成放在品牌行内（普通 flex 元素），
  收起态再靠边挪一点 —— 定位归定位，命中归命中。

| 格式                            | 说明                         |
