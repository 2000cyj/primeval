# 登录页毛玻璃视觉优化设计

## 目标

在不改变登录业务逻辑、DOM 交互和路由流程的前提下，为 `apps/remote-control-vue3/src/views/login.vue` 增加克制的毛玻璃效果，让右侧登录区与左侧工业背景形成统一的层次感。

## 方案

采用整块右侧 `.login-panel` 毛玻璃方案：

- `.login-container` 增加低饱和冷色渐变作为玻璃透底背景。
- `.login-panel` 使用半透明浅色背景、`backdrop-filter: blur(18px) saturate(120%)`、左侧细边框和柔和阴影。
- `.topbar` 与 `.bottombar` 改为半透明背景，保留原有分隔线，避免破坏导航和页脚层次。
- `.input-shell` 保持清晰不模糊，仅调整为半透明白色背景，保留 `:focus-within` 焦点环。
- 宽屏下启用玻璃效果；移动端左侧 hero 隐藏后使用近似不透明背景，避免无可见背景时玻璃失效并减少 GPU 开销。
- `prefers-reduced-transparency: reduce` 下关闭透明和模糊，回退到不透明浅色背景。

## 视觉令牌

- 页面底色：`#dfe8ec` 与 `#f5f7f8` 的冷色渐变。
- 面板：`rgba(247, 248, 249, 0.78)`。
- 面板边缘：`rgba(255, 255, 255, 0.6)`。
- 面板阴影：`rgba(24, 33, 43, 0.1)`。
- 控件底色：`rgba(255, 255, 255, 0.62)`。
- 既有深色文字、青绿色品牌色和焦点状态保持不变，确保可读性与键盘可用性。

## 验收标准

1. 登录、验证码、记住密码、错误提示、跳转等现有行为不变。
2. 桌面宽屏右侧面板能看到背景透出、边缘高光和柔和阴影。
3. 输入框内容和焦点边界清晰，不对输入控件使用 `backdrop-filter`。
4. 视口宽度不超过 620px 时布局保持可用；不依赖 hero 背景时面板不出现过度透明。
5. 支持减少透明度偏好时使用不透明回退样式。
6. 仅修改目标登录页样式，不同步修改注册页，避免扩大本次需求范围。
